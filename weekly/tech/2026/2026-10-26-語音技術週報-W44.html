語音技術週報 W44

本週重點摘要

  1. ElevenLabs 發布 Eleven Realtime v1 S2S 模型：Max 與 Mini 兩款語音對語音模型，Big Bench Audio 98.8%，Full-Duplex-Bench 95.8%（Mini），支援 90+ 語言，10/20 上線。
  2. 螞蟻集團開源 Ming-3.0 語音模型家族：包含 Ming-3.0-asr-tiny（8.6B / 2B 活躍參數），MIT 授權，中英雙語為主，支援方言與熱詞偏向，10/19–20 發布。
  3. OpenAI 推出 GPT-Live-1.1 語音模型：新增 13 個語音角色，涵蓋法、德、印地、日、韓、墨西哥西語，並推出輕量版 Quip，10/15 開始滾動更新。
  4. VoxTurn 統一 turn-taking 框架：單一模型一次回答多個 turn-taking 問題，300ms 延遲預算下英語 false cut-off 僅 11.5%，附 Pipecat/LiveKit 插件，10/15 發布。
  5. ELARSpeech 大規模瀕危語言語音資料集：30,200 小時涵蓋 675 種低資源語言，來自 Endangered Languages Archive，公開釋出模型與建置管線。

1. 語音辨識 (ASR / Speech Recognition)

新聞 / 產業動態

螞蟻集團開源 Ming-3.0 語音模型家族，含 ASR 模型

來源：TechNode / Ant Group InclusionAI（2026-10-20）

螞蟻集團於 10/20 正式發布 Ming-3.0 語音模型家族，共五款模型。其中 Ming-3.0-asr-tiny 是一個 8.6B 參數（約 2B 活躍）的中英雙語語音辨識模型，基於 Ling-tiny-v3 語言骨幹加音訊編碼器。支援中文方言、英文，並可透過熱詞列表（hotword prompting）改善領域術語辨識。權重以 MIT 授權釋出於 Hugging Face 及 ModelScope。10/19 權重上線，10/20 官方公告發布。

TechNode 報導 ｜ Hugging Face

Cactus Compute 發布 Whistle 超輕量端側 ASR 模型

來源：Cactus Compute（2026-10-02）｜本週仍為社群熱議

Cactus Compute 於 10/2 發布 Whistle，僅 16.9 MB 的端側語音辨識模型，純 CPU 運行無需 GPU。支援英、德、法、西、義、荷、波蘭語 7 種語言，自動語言偵測、字級時間戳及語音嵌入。Apache 2.0 授權。廠商宣稱在多數測試中 WER 優於 Whisper base 且速度快 6 倍（Apple M4 Pro），但獨立測試顯示在 TED-LIUM、AMI 等資料集上 Whisper base 仍領先。本週持續在 Hacker News 等社群討論。

論文

Text-Only LLM Correctors Break Correct Transcripts: A Repair-Damage Analysis of Audio Grounding in ASR Error Correction

來源：arXiv 2610.30385

分析純文字 LLM 修正器對 ASR 輸出的實際效果。提出「修復-損傷」分析框架，將 WER 變化拆解為修復的 token、損傷的 token 與插入項，發現文字-only 修正器往往在修復錯誤的同時損壞原本正確的轉錄。比較有無原始音訊作為 grounding 的差異，呼籲 ASR error correction 應結合音訊資訊。

arXiv

Automatic Speech Recognition in the Modern Era: Architectures, Training, and Evaluation

來源：arXiv 2510.12827

一份全面的 ASR 綜述論文，涵蓋現代 ASR 架構（CTC、RNN-T、Attention-based Encoder-Decoder、Conformer 系列）、訓練方法（自監督、半監督、多語言）及評估方法論。適合作為 ASR 領域入門與進階的參考材料。

arXiv

Adapting Speech Foundation Models for Unified Multimodal Speech Recognition with Large Language Models

來源：arXiv 2510.22961

探討如何將語音基礎模型適配至 LLM 架構，實現統一的多模態語音辨識。結合語音編碼器與 LLM 骨幹，在多任務設定下同時支援 ASR、語音翻譯等任務。

arXiv

Probing and Mitigating Hallucinations in Speech-augmented Language Models for ASR via Small Language Models

來源：arXiv 2610.25351

針對語音增強語言模型在 ASR 任務中產生的幻覺問題，提出基於小型語言模型的探測與緩解方法。分析幻覺的產生機制並提出實用的緩解策略。

2. Audio LLM

新聞 / 產業動態

Cloudflare 發布 Clef-omni 開放權重多模態決策模型

來源：Cloudflare（2026-10-09）

Cloudflare 於 10/9 發布 Clef-omni，基於 Qwen3-Omni-30B-A3B-Instruct（30B MoE，3B 活躍參數）後訓練的多模態模型，單次 API 呼叫即可處理文字、圖片、音訊和影片。輸出為結構化決策機率而非自由文字生成。中位回應時間：文字 ~130ms、圖片 ~150ms、21 秒影片+音訊 ~1.5s。權重以 Apache 2.0 授權釋出，已上線 Workers AI，定價 $0.15/M input tokens。

Google 發布 EmbeddingGemma 2 多模態嵌入模型

來源：Google（2026-10）

Google 發布 EmbeddingGemma 2，開放多模態嵌入模型，可將文字、程式碼、圖片、影片和音訊映射到共享嵌入空間。音訊支援使其可用於跨模態語音檢索和語音-文字對齊任務。

3. Speech-to-Speech (S2S)

新聞 / 產業動態

ElevenLabs 發布 Eleven Realtime v1 語音對語音模型

來源：ElevenLabs（2026-10-20）｜報導：The Decoder, JournalDuNet, The New Stack

ElevenLabs 於 10/20 發布兩款語音對語音模型：v1 Max（面向客服等複雜任務）與 v1 Mini（面向低成本自然對話）。Max 在 Big Bench Audio 達 98.8%，工具呼叫完成率 87.1%；Mini 在 Full-Duplex-Bench 得分 95.8%。Max 首音延遲 570ms，Mini 620ms。支援 90+ 語言及 17,000+ 語音庫。透過 ElevenAgents 平台及 OpenAI 相容的 Realtime API 提供（僅 WebSocket，暫不支援 WebRTC）。Mini 為預設推薦，Max 適用頻繁/複雜工具呼叫場景。

ElevenLabs 公告 ｜ The Decoder

OpenAI 發布 GPT-Live-1.1 語音模型

來源：OpenAI（2026-10-15）

OpenAI 於 10/15 開始向所有 ChatGPT Voice 用戶滾動推出 GPT-Live-1.1，為 GPT-Live-1（7 月發布）的後繼版本。新增 13 個語音角色：法語、德語、印地語、日語、韓語、墨西哥西班牙語各 2 個，英語 1 個（Bubbie）。口音更自然，網頁搜尋時「checking...」停頓減少。同步推出輕量版 GPT-Live-1.1 Quip（接替 GPT-Live-1 mini），Go 方案提供 Quip 3 小時/24h，Plus 提供完整版 3 小時/24h，Pro 15 小時/24h。API 版本宣告「即將推出」。

論文

Mind-Paced Speaking: A Dual-Brain Approach to Real-Time Reasoning in Spoken Language Models

來源：arXiv 2510.09592｜作者：Donghang Wu et al. (StepFun, NTU, UNSW)

提出「雙腦」架構解決即時語音模型的推理延遲問題。「構思腦」(Formulation Brain) 負責 CoT 推理並調控「表達腦」(Articulation Brain) 的語音生成節奏，避免模式切換損失推理完整性。在 zero-latency 設定下，Spoken-MQA 數學任務達 92.8% 準確率、URO-Bench 語音對話基準達 82.5 分，優於先前的 think-while-speaking 方法。程式碼開源於 stepfun-ai/Step-MPS。

4. Turn Detection & Semantic VAD

新聞 / 產業動態

Speko 基準測試：OpenAI Semantic VAD 在 backchannel 場景表現不如預期

來源：Speko Benchmarks（2026-10）

Speko 發布了針對 OpenAI gpt-realtime-2 semantic_vad 模式的基準測試結果，標題為「Semantic Was Supposed to Be the Smart One. It Lost.」。測試顯示語義 VAD 在 backchannel（回應詞如「嗯」「對」）處理上表現不佳，容易將回應詞誤判為完整語句結束，導致不必要的打斷。這反映了語義 VAD 在非英語及非標準對話模式中仍有挑戰。

Speko Benchmarks

模型

本週無新模型發布。Pipecat Smart Turn v2 持續作為主要的開源語義 VAD 選項（Hugging Face）。

論文

VoxTurn: Answering Several Turn-Taking Questions in One Pass with One Model

來源：arXiv 2610.21150（2026-10-15 提交）

提出統一的 turn-taking 框架，用單一模型在一次推理中同時回答多個 turn-taking 相關問題。在 300ms 延遲預算下，英語 false cut-off rate 僅 11.5%。在 Pipecat 中截斷率 17%，在 LiveKit 中 9%。模型、程式碼及框架插件均已開源。

arXiv

Thai Semantic End-of-Turn Detection for Real-Time Voice Agents

來源：arXiv 2510.04016

針對泰語即時語音代理的語義結束偵測研究，擴展了 semantic EOT 的語言覆蓋範圍。指出現有開源模型（含 Smart Turn v3）不支援泰語，並提出泰語專用解決方案。
