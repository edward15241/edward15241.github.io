語音技術週報

本週重點摘要

  1. OpenAI GPT-Live (7/8)：全雙工語音模型正式上線 ChatGPT，可同時聽說、自然打斷，複雜問題自動委派 GPT-5.5。語音對話從「半雙工」邁入「全雙工」的里程碑級產品落地。
  2. OpenAI Realtime API 2.1 (7/6)：面向開發者的 S2S API 大幅更新，p95 延遲降低 25%，新增推理深度控制。mini 版本價格為完整版 1/3。
  3. 全雙工架構內建 semantic turn-taking：GPT-Live 的全雙工設計將 turn detection 從獨立模組融入模型本身，每秒多次決策是否接話。
  4. Interspeech 2026 Audio Encoder Challenge 持續進行：XARES-LLM 框架為 LALM 前端 encoder 提供標準化評測基準。
