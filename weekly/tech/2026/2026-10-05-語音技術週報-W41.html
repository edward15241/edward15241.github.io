語音技術週報 W41

語音技術週報 W41 — 2026/09/29–10/05

本週重點摘要

  1. Microsoft 一口氣發布三款語音模型：MAI-Transcribe-2-Streaming（串流 ASR，60 語言，Artificial Analysis 排名第一）、MAI-Voice-2.1 與 MAI-Voice-2.1-Flash（TTS，23 語言，支援語音複製），全部 10/1 上線。
  2. Suno Speech beta 公開：首款能同時生成語音與背景音樂的模型，10/1 對所有用戶開放。
  3. Apple 發表輕量 ASR 糾錯模型：參數量僅 LLM 的 1/15，在 LibriSpeech 上達到 1.5%/3.3% WER，跨架構泛化能力強（2026 年 7 月論文，本週持續獲媒體討論）。
  4. VibeVoice-ASR-Streaming 持續受關注：Microsoft 開源的串流說話人歸屬 ASR 模型（1.5B/7B，MIT 授權），9 月初發布後本週在社群持續熱議。
  5. Semantic VAD 成為語音助理標配：OpenAI、Gradium、Inworld 等平台的語義 VAD 實作在本週各有更新文件或技術部落格。

1. 語音辨識 (ASR / Speech Recognition)

新聞 / 產業動態

Microsoft 發布 MAI-Transcribe-2-Streaming — 串流語音轉文字模型

來源：Microsoft AI｜日期：2026-10-01

Microsoft 首款串流轉錄模型，支援 60 種語言與連續語言偵測。官方宣稱 2.5% WER，語音結束後 0.13 秒即出最終轉錄結果。Artificial Analysis 在 38 個模型中將其排名第一。定價 $0.54/小時（2026 年底前促銷價），透過 Microsoft Foundry、OpenRouter、Vercel AI Gateway 及 Azure Voice Live 提供。

MarkTechPost 報導 ｜ SiliconAngle 報導

Microsoft 同步發布 MAI-Voice-2.1 / MAI-Voice-2.1-Flash TTS 模型

來源：Microsoft AI｜日期：2026-10-01

MAI-Voice-2.1 支援 23 語言、26 地區口音，內建 97 種聲音，同一聲音可跨語言保持一致性。支援語音複製（幾秒參考音檔即可），內建同意機制防止濫用。在 4,000 人圖靈測試中，50.3% 聽眾認為 MAI-Voice 等同或優於真人錄音。Flash 版本推理速度快 55%，端到端延遲 150ms，適合高流量低延遲場景。定價分別為 $22 / $15 per 1M 字元。

Unite.AI 報導

模型更新

VibeVoice-ASR-Streaming（持續受關注）

來源：Microsoft Research（開源）｜發布日期：2026-09-02｜授權：MIT

統一串流 ASR 框架，邊聽邊輸出「誰說了什麼」，不需額外說話人分離階段。支援 10 種語言與自訂熱詞。提供 1.5B 與 7B 兩個版本。這是首批基於 LLM 的端到端串流說話人歸屬 ASR 方案之一，本週在開發者社群持續討論。

GitHub ｜ arXiv 2609.02812

論文

Revisiting ASR Error Correction with Specialized Models

來源：Apple Machine Learning Research｜日期：2026-07（本週持續獲媒體討論）

提出 correction-first decoding，用 ASR 聲學分數對糾錯模型的候選結果重新排序。模型參數量僅 LLM 的 1/15，在 LibriSpeech test-clean/other 上達到 1.5%/3.3% WER，且跨 CTC、Seq2seq、Transducer 三種架構泛化。解決了 LLM 用於 ASR 糾錯時的延遲與幻覺問題。

Apple ML Research ｜ arXiv

NLE: Non-autoregressive LLM-based ASR by Transcript Editing

來源：arXiv 2603.08397｜日期：2026-03

利用交錯填充策略（interleaved padding）與 Transformer 的 identity mapping bias，讓模型聚焦於修正而非重建。NLE++ 在 Open ASR Leaderboard 達到 5.67% 平均 WER，RTFx 高達 1630。

arXiv

3. Speech-to-Speech (S2S)

新聞 / 產業動態

Suno 推出 Speech beta — 首款語音＋音樂一體生成模型

來源：Suno｜日期：2026-10-01

Suno 公開其 Speech beta，號稱首款能將語音與背景音樂作為一體音軌生成的模型。用戶輸入文字內容並描述聲音風格與音樂風格，即可生成配樂語音，如「鋼琴配樂的睡前故事」。經一個月小規模測試後，10/1 對所有行動及網頁用戶開放。已知限制：口音偶爾漂移、停頓可能過長。

Unite.AI 報導

模型

本週無新 S2S 模型發布。

論文（近期重要參考）

RelayS2S: A Dual-Path Speculative Generation for Real-Time Dialogue

來源：arXiv 2603.23346｜日期：2026-03

提出雙路徑投機生成架構：快路徑（端到端 S2S）在偵測到輪替時立即投機生成短前綴並送入 TTS，慢路徑（ASR → LLM 級聯管線）以此前綴為條件生成更高品質的後續內容。兩路徑的交接在文字域完成，共用同一 TTS session 確保聲音一致性。實驗顯示 P90 啟動延遲可媲美純 S2S 模型，同時保留 99% 級聯管線的回答品質。

arXiv ｜ GitHub

PRIME-Speech: Preserving Speech-to-Text LLM Capabilities in Speech-to-Speech Generation

來源：arXiv 2606.30944｜日期：2026-06

提出凍結骨幹的 S2S 轉換框架，僅訓練語音生成模組。將因果音訊後解碼器與凍結骨幹的中間隱藏狀態同步，使 codec token 從模型的推理軌跡生成，而非等待完整文字區塊。避免微調骨幹時 S2T 能力退化的問題。

arXiv

4. Turn Detection & Semantic VAD

新聞 / 產業動態

Semantic VAD 成為語音代理標配技術

來源：多家平台｜日期：2026 Q3-Q4

本週多家平台更新了 Semantic VAD 相關技術文件：OpenAI 的 semantic_vad 根據語意判斷用戶是否說完；Gradium 將語義 VAD 內建於其 STT 中，無需額外元件；Inworld AI 的 Realtime API 結合 Silero VAD 與 Smart Turn 偵測器。與傳統靜音偵測相比，語義 VAD 顯著減少「用戶思考暫停時被打斷」的問題。

Gradium 技術文章 ｜ OpenAI VAD 文件

模型

本週無新 turn-detection 模型發布。

論文（近期重要參考）

Less can be More: What Aspects of Speech Drive End-of-Turn Detection

來源：ACL 2026（arXiv 2609.11066）

對串流 EOT 偵測的聲學、韻律、語義訊號進行系統性消融實驗。結論：聲學＋韻律組合達到最佳準確度-延遲平衡（F1 0.93，400ms 中位延遲，7.8% 誤警報率）。加入文字反而增加過早偵測，韻律特徵具最強類別區分力，文字表徵則重疊嚴重。

ACL 2026 ｜ arXiv

Next-Turn: Duration-Aware Streaming Endpoint Detection via Time-to-Next-Speech-Onset Prediction

來源：Huawei / CUHK / NTU｜arXiv 2606.18094｜日期：2026-06

以 time-to-next-speech-onset 為訓練目標，目標值直接從語音時間戳導出，無需額外標注。在 320ms 內的端點準確度比最強基線提升 25.9%，且與增加停頓數量呈正相關的改善趨勢。

arXiv
